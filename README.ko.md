# ScreenPaste

가벼운 Windows 스크린샷·주석·화면 녹화 도구. 한 번의 키로 캡처하고, 즉시 주석을 달고, 화면에 고정하고, 원하는 영역을 GIF / MP4 / WebP로 녹화하세요.

## 기능

### 캡처
- 전체 화면(다중 모니터 지원)
- **창 / UI 요소 자동 감지**: 창이나 인터페이스 요소(버튼, 패널, 웹 페이지 블록) 위에 마우스를 올리면 자동으로 윤곽이 표시되고 클릭 한 번으로 캡처. **마우스 휠**로 감지 수준 전환(요소 ⇄ 창)
- 드래그로 원하는 영역 선택(크기 표시 포함). **픽셀 돋보기**가 커서를 항상 따라다니며(영역 선택·편집 모두) 십자선, 좌표, 픽셀 색상을 표시 — `C`로 색상 값 복사, `Shift`를 단독으로 눌러 HEX / RGB / HSV 전환
- **선택 후에도 조정 가능**: 모서리와 변 중앙의 핸들을 드래그해 크기 변경. 도구 미선택 시 영역 내부를 드래그해 이동할 수 있으며, 기존 주석은 화면 내용에 고정됩니다

### 주석
캡처 후 커서 옆에 **아이콘 도구 모음**이 나타납니다(드래그로 이동 가능, 화면 가장자리 자동 회피):

- **마커** — 실선 스트로크. 굵기 / 색 / 투명도 조절 가능
- **형광펜** — 반투명 덧칠. 굵기 / 색 / 투명도 조절 가능
- **텍스트** — 글꼴 / 크기 / 색 / 스타일(일반, 굵게, 기울임, 취소선) 선택 가능. 상자 밖을 클릭하면 확정
- **도형** — 사각형 / 둥근 사각형 / 원. 테두리 또는 채우기, 선 굵기와 색 조절 가능
- **직선 / 화살표** — 드래그로 그리기. 양 끝의 화살표를 각각 켜고 끌 수 있으며, 굵기와 색 조절 가능. `Shift`로 45° 단위 스냅
- **이미지 붙여넣기** — PNG / JPEG / WebP 붙여넣기. 드래그로 이동, 휠로 크기 조절
- **흐림** — 가우시안 블러 / 모자이크. 강도 조절 가능. 모든 주석 위에 그려지므로 아래의 선과 도형까지 가릴 수 있고, 드래그로 옮길 수 있습니다(옮긴 위치의 내용을 다시 샘플링). 종류(가우시안 / 모자이크) 기본값은 설정에서 지정할 수 있고, 도구 모음에서 바꾸면 다음번에 그대로 사용됩니다.
- **부분 확대** — 확대할 영역을 드래그로 지정하면 그 옆에 확대 화면이 배치됩니다: 사각형 / 둥근 사각형 / 원, 배율(1.2~10×) · 테두리 굵기와 색 · 연결선 · 그림자 · 부드럽게(끄면 픽셀 격자가 그대로 보임), 확대 내용에 다른 주석을 포함할지 설정할 수 있습니다. 확대 화면과 **원본 영역 테두리 모두 언제든 드래그로 옮길 수 있습니다** — 테두리를 옮기면 확대되는 내용이 바뀌고 연결선도 새 위치를 가리킵니다. 돋보기를 선택하면 테두리에 **핸들 8개가 나타나 크기를 조절**할 수 있고(확대 화면도 배율에 맞춰 함께 조절됩니다), 휠로 배율을 조정합니다
- **직접 선택 / 이동** — 배치된 주석 위에 마우스를 올려 **바로 드래그로 이동**. `Delete`로 삭제. 이동·삭제 모두 실행 취소 가능
- **색상 선택기** — Hex 입력, RGB, 투명도 지원(반투명 색은 체커보드 위에서 미리보기). 사용자 지정 색은 다음 실행에도 기억되며 우클릭으로 삭제 가능
- **실행 취소 / 다시 실행** — 버튼과 단축키 모두 지원. 모든 슬라이더에 실시간 숫자 표시

### 출력
- 클립보드로 복사
- PNG / JPG로 저장(다른 이름으로 저장 또는 기본 폴더로 빠른 저장)
- **화면에 고정**: 이미지가 항상 위에 떠 있습니다. 드래그로 이동, 휠로 커서 위치를 중심으로 크기 조절, 우클릭 메뉴. 더블 클릭, `Esc`, `Ctrl+W`로 닫아도 `F3`으로 다시 불러올 수 있습니다(`Shift+Esc`는 폐기). 여러 개 고정 시 Esc는 포커스된 것부터 닫고, 포커스가 없으면 모두 닫습니다. `F3`으로 클립보드 내용도 고정할 수 있습니다

### 영역 녹화
- 전용 전역 단축키(기본 **F2**): 드래그로 녹화 영역을 선택하거나 **창을 클릭해 자동 감지**(휠로 창/요소 레벨 전환, 캡처와 동일)해 시작, 다시 누르면(또는 중지 버튼) 종료
- 녹화 중 빨간 테두리로 영역 표시. 타이머와 중지 버튼이 있는 작은 바 제공
- 녹화 후 **편집기**가 열립니다: 반복 미리보기, 타임라인 트림 핸들(`Space` 재생, `←`/`→` 프레임 이동, `I`/`O`로 시작/끝 지점 설정), 진행률 표시와 함께 내보내기
- **녹화 중 빨간 테두리를 드래그해 녹화 영역 이동 가능** — 내부는 녹화 대상 조작이 그대로 가능
- 편집기에는 캡처와 동일한 **주석 도구**(텍스트 / 도형 / 직선·화살표 / 이미지 / 가우시안 블러 / 모자이크, 옵션 행 포함. 주석은 직접 드래그 이동, `Delete` 삭제); `Ctrl+C`로 빠른 내보내기 후 파일을 클립보드로
- **GIF / MP4 / WebP**로 내보내기(편집기에서 바로 전환 가능). 설정에서 편집기를 건너뛰고 즉시 저장도 가능
- 마우스 커서 녹화 선택 가능, 프레임 속도 10–30 fps
- **오디오**: 시스템 소리(루프백) / 마이크 / 둘 다 믹스를 설정에서 선택 가능. 소리는 **MP4**에만 저장됩니다(GIF·WebP는 무음). 사용 가능한 오디오 장치가 없으면(원격 데스크톱에서 흔함) 무음 녹화로 자동 전환됩니다
- 번들된 `ffmpeg`로 인코딩. 별도 설치 불필요

### 기타
- 전역 단축키(**F1** 캡처, **Ctrl+F1** 캡처 후 복사, **Shift+F1** 사용자 지정 캡처, **F2** 녹화, **F3** 붙여넣기 / 이미지 복원, **Shift+F3** 고정 이미지 숨기기/표시, 모두 사용자 지정 가능)와 **시스템 트레이** 아이콘에서 실행
- **다국어 지원**: 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español(기본은 시스템 언어)
- **라이트 / 다크 / 시스템 따르기** 테마. 모던한 라운드 UI와 다크 제목 표시줄
- 통합 **설정 창**: 언어, 단축키, 테마, 시작 시 실행, 저장 폴더, 주석 기본값(흐림 종류), 녹화 형식 / 프레임 속도(단축키 칸은 키 조합을 누르기만 하면 설정. 캡처 중과 고정 이미지의 키도 모두 다시 지정 가능)
- **Windows 시작 시 자동 실행**(선택)
- **자동 업데이트**: GitHub Releases로 새 버전 확인(설정에서 켜고 끄기, 수동 확인 가능). 클릭 한 번으로 다운로드 및 설치(진행률과 속도 표시)

## 설치

[Releases](https://github.com/taida957789/ScreenPaste/releases)에서 다운로드:

- **`ScreenPaste-<version>-setup.exe`** — 설치 버전(관리자 권한 불필요, `%APPDATA%\ScreenPaste`에 설치, 시작 메뉴 바로가기와 제거 프로그램 포함)
- **`ScreenPaste-<version>-win-x64-portable.zip`** — 무설치 포터블 버전

둘 다 자체 포함형으로 **별도의 .NET Runtime이 필요 없으며**, 영역 녹화용 `ffmpeg`도 번들되어 있습니다.

## 빠른 시작

![도구 모음](screenshots/ui.png)

1. 실행하면 시스템 트레이에 상주합니다. **F1**(또는 트레이 아이콘 더블클릭)로 캡처 시작.
2. 창이나 UI 요소 위에 마우스를 올려 자동 윤곽 표시 → 클릭으로 캡처, 또는 드래그로 영역 선택.
3. 팝업 도구 모음에서 도구를 고르고 매개변수를 조정해 선택 영역에 주석 작성.
4. **복사 / 저장 / 고정**으로 출력. `Esc`로 캡처 종료(먼저 확인하며, "다시 묻지 않음" 선택 가능).

녹화: **F2**를 누르고 드래그로 영역을 선택하면 녹화 시작. 다시 **F2**(또는 중지 버튼)로 종료한 뒤 편집기에서 미리보기·트림하고 GIF/MP4/WebP로 내보내기(설정에서 즉시 저장으로 변경 가능).

## 단축키 목록

단축키는 Snipaste에 같은 동작이 있으면 그 배치를 따르며, 표에는 기본 키가 나와 있습니다. 전역 단축키는 설정 → "단축키"에서, 캡처 중과 고정 이미지의 모든 키는 설정 → "앱 내 단축키" → "키 사용자 지정…"에서 바꿀 수 있습니다(동작마다 키 두 개까지, 키가 겹치면 경고). 고정된 것은 텍스트 상자 자체의 편집 키와 드래그 중에 누르고 있는 보조키(`Shift` 등)뿐입니다.

> **이번 버전의 변경 사항**
> - **고정 이미지를 더블 클릭하면 닫힙니다**(처음에는 먼저 확인). 설정 → "고정 이미지"에서 썸네일 전환 또는 동작 없음으로 바꿀 수 있습니다.
> - `Esc` / `Ctrl+W`로 닫은 고정 이미지는 **다시 불러올 수 있습니다**: 마지막 붙여넣기 이후 클립보드가 바뀌지 않았다면 `F3`으로 원래 위치에 돌아옵니다. `Shift+Esc`는 **영구 폐기**합니다.
> - 휠로 고정 이미지를 확대/축소하면 **커서 위치가 중심**이 됩니다(설정 → "고정 이미지"에서 왼쪽 위 고정으로 바꿀 수 있음).
> - 돋보기의 색상 형식(HEX → RGB → HSV)은 **`Shift`를 단독으로 눌렀다 뗄 때** 바뀌므로, `Shift`+드래그나 `Shift`+클릭으로는 더 이상 바뀌지 않습니다.

### 전역

| 키 | 동작 |
|---|---|
| `F1` | 캡처 시작(사용자 지정 가능) |
| `Ctrl+F1` | 캡처 후 복사: 영역을 고르면 바로 클립보드로(사용자 지정 가능) |
| `Shift+F1` | 사용자 지정 캡처: 대화 상자에서 영역과 지연 시간 설정(사용자 지정 가능) |
| `F2` | 영역 녹화 시작 / 중지(사용자 지정 가능) |
| `F3` | 클립보드 내용(이미지, 이미지 파일, 색상 값, 텍스트)을 커서 위치에 고정. 클립보드가 바뀌지 않았을 때 다시 누르면 마지막으로 닫은 이미지를 다시 불러옴(사용자 지정 가능) |
| `Shift+F3` | 모든 고정 이미지 숨기기 / 표시(사용자 지정 가능) |
| 기본값 미지정 | 고정 이미지 클릭 통과(커서 아래 이미지가 클릭을 통과시킴), 캡처 후 고정, 캡처 후 복사·고정, 지난 영역 다시 복사, 전체 화면 복사, 활성 창 캡처, 커서가 있는 화면 캡처, 지연 캡처, 캡처 기록 지우기: 설정 → "단축키" / "추가 단축키"에서 지정 |
| 트레이 아이콘 | 더블 클릭하면 캡처 시작. 메뉴에는 사용자 지정 캡처, 클립보드에서 붙여넣기, 고정 이미지 숨기기/표시, "모든 고정 이미지를 클릭 가능하게", 그리고 설정은 그대로 둔 채 캡처 단축키를 끄고 켜는 "캡처 단축키 (F1)"(예: 게임에 F1을 양보할 때)도 있습니다 |

### 캡처: 영역 선택 중

| 키 | 동작 |
|---|---|
| 클릭 / 드래그 | 강조된 창이나 UI 요소 캡처 / 원하는 영역 선택 |
| 휠 | 감지 수준 전환(UI 요소 ⇄ 창) |
| `Tab` | UI 요소 감지와 창 감지 전환 |
| `Space` | 강조된 영역 선택 |
| `Ctrl+A` | 커서가 있는 화면, 한 번 더 누르면 모든 화면 선택 |
| `Shift`+드래그 | 정사각형으로 선택 |
| 드래그 중 `Space` 누르고 있기 | 크기를 바꾸지 않고 영역 이동 |
| `W` `A` `S` `D` / 방향키 | 커서를 1픽셀 이동(누르고 있으면 가속). 드래그도 따라옴 |
| `Alt` 단독 누르기 | 십자 안내선 표시 / 숨기기(상태 기억) |
| `C` | 돋보기가 가리키는 픽셀 색상 값 복사 |
| `Shift` 단독 누르기 | 색상 표시를 HEX → RGB → HSV 순서로 전환 |
| `R` / `Shift+R` | 이전 캡처의 영역을 앞 / 뒤로 이동 |
| `,` / `.` | 캡처 기록을 앞 / 뒤로 이동(이전 캡처, 주석은 합쳐진 상태, 메모리에만 보관) |
| `` ` `` 또는 `!` | 캡처 안의 마우스 커서 표시 / 숨기기(상태 기억) |
| `F5` | 오버레이 아래 화면을 다시 캡처 |
| 우클릭 | 선택 중인 영역 버리기. 선택 중이 아니면 캡처 종료 |
| `Esc` | 캡처 종료 |

### 캡처: 편집 및 주석 중

| 키 | 동작 |
|---|---|
| 핸들 드래그 | 영역 크기 조절(`Ctrl`: 중심 기준, `Space` 누름: 대신 이동) |
| 영역 안쪽 드래그(도구 미선택) | 영역 이동(`Shift`: 한 축으로만) |

| 키 | 동작 |
|---|---|
| 드래그 | 이동(누른 채로 `W` `A` `S` `D`: 1픽셀 이동) |

| 우클릭 / `Menu` 키 | 메뉴 |
| `Ctrl`+클릭 | 다중 선택에 추가 / 제외. 선택한 이미지는 함께 이동·불투명도 변경·닫기 |
| `Esc` / `Ctrl+W` | 닫기(`F3`으로 다시 불러올 수 있음) |

| 포커스된 이미지가 없을 때 `Esc` | 표시 중인 모든 고정 이미지 닫기(다시 불러올 수 있음) |
