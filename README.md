# ScreenPaste

輕巧的 Windows 截圖與標註工具：一鍵截圖、即時標註、釘選到螢幕。

## 功能

### 截取
- 整個畫面（支援多螢幕）
- **視窗與 UI 元素自動辨識**：滑鼠移到視窗或介面元素（按鈕、面板、網頁區塊）上自動描出範圍，點一下即截取；**滾輪**可切換偵測層級（元素 ⇄ 視窗）
- 拖曳框選自訂範圍，附尺寸標示；**像素放大鏡**全程跟隨游標（框選與編輯模式皆顯示），提供十字定位、座標與像素顏色，`C` 複製色值、單按 `Shift` 依序切換 HEX / RGB / HSV
- **框選後可再調整**：拖曳四角與邊中點的把手改變範圍；未選工具時拖曳選區內部可整體移動，已畫的標註會固定在畫面內容上

### 標註
截取後在滑鼠旁彈出**圖示工具列**（可拖曳移動、自動避開螢幕邊界）：

- **麥克筆** — 實心筆觸，可調粗細 / 顏色 / 透明度
- **螢光筆** — 半透明疊色，可調粗細 / 顏色 / 透明度
- **文字** — 可選字體 / 大小 / 顏色 / 樣式（正常、粗體、斜體、刪除線）；點擊框外即完成輸入
- **形狀** — 方形 / 圓角方形 / 圓形，外框或填滿，可調線條粗細與顏色
- **直線 / 箭頭** — 拖曳畫線，兩端可各自切換是否為箭頭，可調粗細與顏色；按住 `Shift` 吸附 45° 角
- **貼圖** — 貼上 PNG / JPEG / WebP 圖片，可拖曳移動、滾輪縮放
- **模糊** — 高斯模糊 / 馬賽克，可調模糊程度；蓋在所有標註之上，能遮住其下的筆畫與形狀，並可直接拖曳移動（移動後重新取樣新位置的畫面）；類型（高斯 / 馬賽克）可於設定指定預設，工具列切換後也會記住最後一次的選擇
- **局部放大** — 拖曳框出要放大的區域，旁邊自動放出放大檢視：方形 / 圓角 / 圓形，可調倍率（1.2–10×）、邊框粗細與顏色、連接線、陰影、平滑（關閉即顯示硬邊像素格），以及放大內容是否含其他標註；放大檢視與**來源外框都可以隨時拖曳移動** — 移動來源外框即改變放大的內容，連接線隨之重新指向；選取放大鏡後，來源外框會出現**八個把手可調整大小**（放大檢視依倍率同步縮放），滾輪則可改倍率
- **直接選取 / 移動** — 滑鼠移到任何已畫的標註上即可**直接拖曳移動**，`Delete` 刪除；移動與刪除皆可復原
- **色彩選擇器** — 支援 Hex 輸入、RGB 與透明度調整（半透明以棋盤格預覽）；自訂顏色會跨次記住，右鍵色票即可移除
- **復原 / 重做** — 按鈕與熱鍵皆可，所有滑桿附即時數值顯示

### 輸出
- 複製到剪貼簿
- 儲存為 PNG / JPG（另存或快速存到預設資料夾）
- **釘選到螢幕**：影像浮於最上層，可拖曳、滾輪以游標為中心縮放、右鍵選單；按兩下、`Esc` 或 `Ctrl+W` 關閉後可按 `F3` 叫回（`Shift+Esc` 永久銷毀）；釘多張時 Esc 先關聚焦的那張、無聚焦則全關。`F3` 也能把剪貼簿內容貼成貼圖

### 區域錄影
- 專屬全域熱鍵（預設 **F2**）啟動：拖曳框選要錄製的範圍，或**點擊視窗自動辨識**（滾輪切換視窗／元件層級，與截圖相同），再按一次熱鍵（或點停止鈕）結束
- 錄製時以紅框標示範圍，旁邊小工具列顯示計時與停止鈕
- 結束後開啟**編輯器**：循環預覽、拖曳時間軸把手**修剪頭尾**（`Space` 播放、`←→` 逐格、`I`/`O` 設起訖點），匯出時顯示進度
- **錄製中可拖曳紅框邊框移動錄製範圍**，框內維持可正常操作被錄的視窗
- 編輯器具備與截圖相同的**標註能力**（文字 / 形狀 / 直線箭頭 / 貼圖 / 高斯模糊 / 馬賽克，含完整選項列，標註可直接拖曳移動、`Delete` 刪除）；`Ctrl+C` 快速匯出並將檔案放上剪貼簿
- 匯出格式 **GIF / MP4 / WebP** 於編輯器直接切換；也可於設定改為「錄完直接儲存」跳過編輯器
- 可錄製滑鼠游標、可設定影格率（10–30 fps）
- **收音**：系統聲音（loopback）／麥克風／兩者混音，可於設定選擇；聲音僅存於 **MP4**（GIF、WebP 無聲）。若無可用音訊裝置（遠端桌面常見）會自動降級為無聲錄影
- 由隨附的 `ffmpeg` 進行編碼，無需另外安裝

### 其他
- 全域熱鍵（截圖 **F1**、截圖並複製 **Ctrl+F1**、自訂截圖 **Shift+F1**、區域錄影 **F2**、貼上／叫回貼圖 **F3**、隱藏／顯示貼圖 **Shift+F3**，皆可自訂）與**系統匣**圖示啟動
- **多國語言**：繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español（預設跟隨系統）
- **淺色 / 深色 / 跟隨系統**主題
- 集中式**設定視窗**：語言、熱鍵、主題、開機啟動、儲存資料夾、標註預設值（模糊類型）；熱鍵欄位可直接按組合鍵設定，截圖與貼圖內的每個按鍵也都能重新指定
- 可設定**開機自動啟動**
- **自動更新**：透過 GitHub Releases 檢查新版（可於設定開關、或手動立即檢查），有更新時詢問並一鍵下載安裝，下載時顯示進度與速度

## 安裝

到 [Releases](https://github.com/taida957789/ScreenPaste/releases) 下載：

- **`ScreenPaste-<版本>-setup.exe`** — 安裝版（免系統管理員權限，安裝於 `%APPDATA%\ScreenPaste`，含開始功能表捷徑與解除安裝程式）
- **`ScreenPaste-<版本>-win-x64-portable.zip`** — 免安裝綠色版

兩者皆為自我包含，**無需另外安裝 .NET Runtime**，並已隨附 `ffmpeg`（供區域錄影使用）。

## 快速使用

![工具列](screenshots/ui.png)

1. 啟動後常駐系統匣，按 **F1**（或雙擊系統匣圖示）開始截圖。
2. 滑鼠移到視窗自動描框、點擊截取，或拖曳框選自訂範圍。
3. 在彈出的工具列選工具、調整參數，於選區上標註。
4. 按 **複製 / 儲存 / 釘選** 輸出；`Esc` 離開截圖（會先詢問，可勾選不再提醒）。

錄影：按 **F2** 拖曳框選範圍即開始錄製，再按一次 **F2**（或點停止鈕）結束；接著在編輯器中預覽、修剪頭尾並選擇 GIF/MP4/WebP 匯出（設定中可改為錄完直接儲存）。

## 快捷鍵一覽

快捷鍵盡量沿用 Snipaste 的配置，下表列出的是預設按鍵。全域熱鍵可在設定 →「熱鍵」中修改；截圖與貼圖內的每個按鍵都可在設定 →「截圖與貼圖內的快捷鍵」→「自訂按鍵…」中重新指定（每個動作最多兩組按鍵，按鍵衝突時會提示），只有文字框本身的編輯鍵與拖曳時按住的修飾鍵（如 `Shift`）固定不變。

> **本版變更**
> - **按兩下貼圖會將它關閉**（第一次會先詢問）。可在設定 →「貼圖」改為切換縮圖或不動作。
> - `Esc`／`Ctrl+W` 關閉的貼圖**可以叫回**：只要剪貼簿自上次貼上後沒有變更，按 `F3` 貼圖就會回到原位。`Shift+Esc` 則會**永久銷毀**貼圖。
> - 滾輪縮放貼圖時**以滑鼠游標為中心**（可在設定 →「貼圖」改為固定左上角）。
> - 放大鏡的色值格式（HEX → RGB → HSV）改為**單按 `Shift`**（單獨按下再放開）才切換，`Shift`＋拖曳與 `Shift`＋點擊不再改變格式。

| 方向鍵 | 移動一個像素（按住會加速） |
| `Ctrl+C` / `Ctrl+Insert` | 複製 |
| `Ctrl+Alt+C` | 以 PNG 檔案複製 |
| `Ctrl+S` / `Ctrl+Shift+S` | 另存 / 快速儲存 |
| `Ctrl+P` | 列印 |
| `Ctrl+V` | 改為顯示剪貼簿的內容 |
| `Ctrl+Shift+C` | 複製文字貼圖的原始文字 |
| `Ctrl+A` | 選取所有顯示中的貼圖 |
| `Ctrl+Shift+P` | 開啟設定 |
| 單按 `Alt` | 開啟 / 關閉放大鏡：`C` 複製游標下的顏色，單按 `Shift` 依序切換 HEX → RGB → HSV，`W` `A` `S` `D` 讓游標移動一個像素 |
| 拖入圖片檔 | 取代貼圖的圖片（`Shift`：開成新的貼圖） |

### 錄影編輯器

| 按鍵 | 功能 |
|---|---|
| `Space` | 播放 / 暫停 |
| `←` / `→` | 逐格前進 / 後退 |
| `Home` / `End` | 跳至修剪起點 / 終點 |
| `I` / `O` | 於播放位置設定修剪起點 / 終點 |
| `Ctrl+C` | 快速匯出並將檔案複製到剪貼簿 |

設定（熱鍵、工具預設、主題、開機啟動、錄影格式/影格率等）皆可於系統匣選單 →「設定…」的視窗中調整。
